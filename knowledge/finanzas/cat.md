# CAT: comparar el costo de un crédito

El Costo Anual Total, CAT, resume el costo del financiamiento como porcentaje anual para facilitar comparaciones. Considera intereses, comisiones y otros gastos inherentes al crédito conforme a la metodología de Banco de México. El CAT informativo se calcula sin IVA.

## Comparación de alternativas
Revisa también importe, plazo, pago periódico y cargos adicionales. Comparar solo la mensualidad puede ocultar diferencias en duración o costo. Sin esos datos no es posible calcular el costo total de una oferta ni declarar que una opción conviene más. Esta guía no ofrece un crédito ni una aprobación.
