# Fondo de emergencia: una reserva para imprevistos

Un fondo de emergencia es dinero apartado para gastos necesarios que no habías previsto o para una interrupción del ingreso. Conviene distinguirlo del dinero para compras planeadas. La referencia educativa de tres a seis meses se refiere a gastos básicos y debe adaptarse a cada situación.

## Cómo empezar
Identifica tus gastos esenciales, calcula una meta orientativa y elige una aportación sostenible. Puedes comenzar con una reserva menor y aumentarla gradualmente. Conserva claridad sobre qué parte de tus ahorros ya tiene otro propósito. Esta guía no recomienda una institución ni promete rendimientos.
